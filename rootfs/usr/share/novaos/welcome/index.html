Welcome to NovaOS

This page is stored on your computer, so it works offline.

Start

Open the Applications menu in the panel, or press Alt+F3 to search and launch apps.

Personalize

Open Settings to switch dark/light mode, change the accent colour and pick a wallpaper.

Files

Super+E opens Files. Right-click the desktop for more options.

Terminal

Ctrl+Alt+T opens the terminal.

Install

In the live session, double-click Install NovaOS on the desktop to install it to the virtual disk.

Internet

When the VM has network access, type an address in the bar above to browse the web.
