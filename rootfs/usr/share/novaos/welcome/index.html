Welcome to NovaOS

This page is stored on your computer, so it works offline.

Start

Click the star in the middle of the taskbar, or press Super, and start typing to find any app or file.

App Store

Open App Store to install apps and games with one click, including thousands from Flathub.

Office

Writer, Impress and Calc open and save Word, PowerPoint and Excel files. Paint is for quick drawings.

Make it yours

Right-click the desktop for wallpapers, or the taskbar → Enter Edit Mode to move and resize it. Everything else is in Settings.

Smooth graphics

In UTM choose the display card virtio-gpu-gl-pci (GPU Supported). Check it in System Info → Graphics.

Install

In the live session, double-click Install NovaOS on the desktop to install it to the virtual disk.
